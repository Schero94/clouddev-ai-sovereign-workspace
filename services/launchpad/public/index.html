DESKTOP

Connect with VS Code Remote-SSH

Use the private key file supplied by the operator. The key stays on your computer.

SSH proxy details are not configured. The operator can map the IDE TCP proxy domain and port to IDE_SSH_PROXY_HOST and IDE_SSH_PROXY_PORT.

Paste the block into your local SSH config. In VS Code, choose Remote-SSH: Connect to Host… from the Command Palette, then select clouddev.

FORGEJO

Connect Git over SSH

Git uses the separate Ed25519 key created by git-setup. The key stays in the shared workspace, and its contents are never shown here.

Git SSH proxy details are not configured. Forgejo browser access and sign-in remain on HTTPS.

Save the block in the shared workspace's ~/.ssh/config. Clone with git@forgejo:<owner>/<repo>.git. Use the Forgejo link above to sign in in your browser.

FIRST RUN

Finish your setup

  1. 01Set your Git identityIn the IDE terminal, run git config --global user.name and git config --global user.email.
  2. 02Connect ForgejoCreate a regular, non-admin Forgejo account and a private repository. In the IDE, run git-setup and add its public SSH key to that account.
  3. 03Connect an AI providerOpen OmniRoute, add your provider credentials, then create a scoped inference key.
  4. 04Connect the IDE to OmniRouteIn the IDE terminal, run ai-setup and follow the prompts. It stores only the scoped gateway key.
  5. 05Test an agentRun ai-status, then start an agent with ai-codex or ai-claude.

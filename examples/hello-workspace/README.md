# Hello workspace

This tiny project gives you a safe first file to open and commit. It is plain
HTML and CSS. It has no install step, dependencies, or startup scripts.

## Open it

1. In Browser VS Code, choose **File → Open Folder**.
2. Open `/workspace/projects/hello-workspace`.
3. Open `index.html` to edit the page and `styles.css` to change its colors.
4. If you want a browser preview, start a project server only after reviewing
   its command. Never run a repository script you have not inspected.

This directory is a sample. Replace its text and layout with your own project.
